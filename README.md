# CS50x — Introduction to Computer Science

My solutions and projects for **CS50x**, Harvard University's Introduction to Computer Science.

This repository contains my work from the course, covering fundamental concepts in computer science and programming, from low-level programming in C to Python, SQL, and web development.

> **Course:** CS50x — Introduction to Computer Science
> **Institution:** Harvard University
> **Course Website:** https://cs50.harvard.edu/x/

---

## About CS50x

CS50x is Harvard University's introduction to the intellectual enterprises of computer science and the art of programming.

The course focuses on computational thinking and problem solving while introducing fundamental concepts such as:

* Algorithms
* Data structures
* Abstraction
* Memory
* Resource management
* Databases
* Web development
* Security
* Software engineering

The course begins with C to develop a deeper understanding of programming and computer systems, and later introduces higher-level languages and technologies including Python, SQL, HTML, CSS, JavaScript, and Flask.

## Problem Sets

The repository contains my implementations for the CS50x problem sets.

The assignments progressively introduce new programming concepts and require applying them to increasingly complex problems.

### Problem Set 0 — Scratch

An introduction to computational thinking and programming concepts using Scratch.

### Problem Set 1 — C

Introduction to C programming, including:

* Variables and data types
* Conditionals
* Loops
* Functions
* User input
* Integer arithmetic

### Problem Set 2 — Arrays

Working with:

* Arrays
* Strings
* Characters
* Command-line arguments
* Cryptography

### Problem Set 3 — Algorithms

Exploring:

* Searching
* Sorting
* Algorithm analysis
* Computational efficiency

### Problem Set 4 — Memory

Working with:

* Pointers
* Memory addresses
* Dynamic memory allocation
* File manipulation
* Image processing

### Problem Set 5 — Data Structures

Implementing and working with fundamental data structures.

### Problem Set 6 — Python

Applying programming concepts using Python and exploring the differences between C and a higher-level programming language.

### Problem Set 7 — SQL

Working with relational databases and SQL, including:

* Tables
* Primary and foreign keys
* Queries
* Filtering
* Aggregation
* Joins
* Relational database concepts

### Problem Set 8 — HTML, CSS, JavaScript

Introduction to client-side web development using:

* HTML
* CSS
* JavaScript

### Problem Set 9 — Flask

Introduction to web application development using:

* Python
* Flask
* SQL
* HTML
* CSS
* JavaScript

## Learning Approach

The goal of this repository is not simply to collect solutions, but to document hands-on practice with fundamental computer science concepts.

The emphasis is on understanding the underlying concepts, developing problem-solving skills, and learning to reason about how and why a solution works.
